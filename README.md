# ✅ To-Do List

A simple Python-based To-Do List application that helps users create and manage their daily tasks.

This project was created to practice Python programming fundamentals, data handling, and user input.

## 🚀 Features

- ➕ Add new tasks
- 📋 View existing tasks
- ✅ Manage tasks
- 🗑️ Remove tasks
- 🖥️ Simple command-line interface
- ⚡ Easy to use

## 🛠️ Technologies Used

- Python
- Lists
- Functions
- Loops
- Conditional statements
- User input
